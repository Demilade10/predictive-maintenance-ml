# Dataset attribution

This project includes the **AI4I 2020 Predictive Maintenance Dataset**, donated by Stephan Matzka to the UCI Machine Learning Repository in 2020.

- Dataset page: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset
- DOI: https://doi.org/10.24432/C5HS5C
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0)

The dataset is synthetic and intended to reflect real industrial predictive-maintenance data.
